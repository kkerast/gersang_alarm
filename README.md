# 🔍 사통팔달 키워드 감시 도구 (거상용 패킷 모니터)

> ⚠ 본 도구는 천하제일상 거상과 무관한 **비공식 개인 도구**입니다.

이 도구는 거상 게임에서 특정 키워드가 포함된 **채팅 패킷**을 감지하고,
사용자에게 **경고음 및 로그 출력**을 제공하는 비상업적 목적으로 제작된 모니터링 툴입니다.

---

## ✨ 주요 기능

-   ✅ 특정 키워드가 포함된 채팅 실시간 감지
-   ✅ 시스템 트레이 알림 또는 경고음 발생
-   ✅ 모든 채팅 로그 기록 (텍스트 보기)
-   ✅ Windows 전용 GUI 인터페이스 (Tkinter)
-   ✅ `config.json`에 키워드 저장
-   ✅ MP3 또는 기본 알림음 선택
-   ✅ 알람 지속 시간 설정 (1~10초)

---

## 📦 코드 실행 방법

1. Python 3.8 이상 설치
2. 필수 패키지 설치:
    ```bash
    pip install pygame scapy psutil
    ```
3. exe 파일 만들기
   ```bash
   pip install pyinstaller
   pyinstaller --noconsole --onefile gersang_alarm.py
    ```

## 📦 설치 및 사용 방법

1. npcap-1.81 을 설치한다 (설치할때 I agree -> install 만 누르시면됨)

2. 압축을풀어서 사통팔달 감시를 실행시킨다.

3. 감시할 키워드를 , 로 구분하여 입력한다 ( 예시를 위해 봉돌,불깃,팜,팝니다,삼,삽니다 키워드가 등록되어있음)

4. 거상을 실행해서 서버에 접속한다.

5. 감시 시작을 누른다.

6. 키워드가 포함된 사통이 올라오면 알람이(경고음 2초) 발생한다.

p.s 패킷 감시프로그램이 설치되어야 해서 보안에 신경쓰이시는 분은 사용하시기 힘들듯합니다...
